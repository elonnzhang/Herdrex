- Live tests of the whole bridge through both command lines: an operation through `herdr` must show up in what `rex` reads, and the other way round. They skip unless `HERDR_TEST_BIN` and `REX_TEST_BIN` name the two binaries.
- Each run starts its own Herdr server under `/tmp/hxe2e*` with `pkg/herdr/cli.StartServer`, which refuses to touch the user's Herdr, and serves the bridge in-process on a loopback port. `rex` runs with `HOME` in that directory and `--autostart=false`, so it never reads or writes the real Rex home.
- Checks compare what each side reports, not what the bridge computed: Rex rects against Herdr's cell rects, split ratios, focus, zoom and labels. A check reads Rex after a `session_view_changed` event, so Herdr changes must reach Rex by event, not only by the fresh snapshot of `session.view`.
