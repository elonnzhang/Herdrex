Helpers that know nothing of Herdr or Rex; keep it that way, and put anything that names a Herdr or Rex concept in `cmd/herdrex` or `pkg/herdr`. `ssh.go` has the remote-command quoting (`RemoteCommand` quotes for the login shell, then runs `sh -c`), `LockDir` (a private `/tmp` directory held by flock, one per user and seed) and `TailWriter`; `sshtunnel.go` and `sshmux.go` are the three ways to reach remote Unix sockets (`Forward`, `Mux`, `Stdio`), all returned as a `Tunnel`, and the caller probes each one because some relays accept `-L` and refuse every channel. `net.go` classifies addresses (`LAN`, `Tailscale`), chooses and binds the ones to serve (`SelectLAN`, `ListenSelected`, `ListenAll`, `ListenAutoPort`) and holds the `--allow` list (`AllowList`). The bridge has no authentication, so loopback callers are always admitted, Tailscale-range callers only on a Tailscale listener address (`http.LocalAddrContextKey`; the range is also carrier and VPC CGNAT), and any other caller only through `--allow`, until `ExpireAfter` ends it; `Middleware` holds the connections that only `--allow` admitted (it needs `ConnContext` on the `http.Server`) so that `CloseAllowed` ends them at expiry; a change here is a change to who can use every pane, so test the refusal as well as the admission. `unix.go` has `ListenUnix`, the bridge's Unix socket (mode 0600 from creation, stale sockets replaced, live ones and other files refused), and `OnUnixSocket`, which `AllowList.Middleware` uses to let those callers through. `RemoteCommand` sends a script of several lines base64-encoded on one line, because some relays drop a remote command with a newline.
