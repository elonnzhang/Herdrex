# Note For Coding Agents

Herdrex serves a Herdr server as a Rex host: Rex.app and the `rex` CLI connect to it over Rex's WebSocket protocols, and the bridge maps each call and event onto Herdr's sockets. README.md has the user view.

## Layout

- `pkg/rex`: Rex protocol types, server framework (`pkg/rex/server`), client and terminal stream. Knows nothing of Herdr.
- `pkg/herdr`: Herdr clients, one subpackage per protocol. Knows nothing of Rex.
- `internal/bridge`, `internal/model`: the mapping between the two. `cmd/herdrex`: the binary.

Rules every Rex server needs go in `pkg/rex/server`; the bridge only answers how a Rex method maps onto Herdr. Before changing a package, read its AGENTS.md.

## Commands

```sh
go build ./... && go vet ./... && go test ./...
go test -run TestDecoder ./pkg/rex/termstream/   # one test
go build -o bin/herdrex ./cmd/herdrex
```

The `staticcheck` on PATH was built with Go 1.25 and cannot load this module; use `go vet`.

Live tests skip unless an env var names a server, and they create sessions, tabs or attachments there: `REX_TEST_SERVER=<url>` (`pkg/rex/client`), `HERDR_TEST_SOCKET=<api socket>` (`pkg/herdr/jsonapi`, `term`, `endpoint`; point it only at a Herdr started for the test, as `docs/TESTING.md` shows), `HERDR_TEST_BIN=<herdr binary>` (`pkg/herdr/cli`; starts its own server under `/tmp/hxc*`).

## Running environment

The bridge runs on `127.0.0.1:7392` against the Herdr at `/tmp/rexbridge/herdr.sock`, and Rex.app uses it as host `herdr`. Restart it after a rebuild:

```sh
kill $(lsof -nP -iTCP:7392 -sTCP:LISTEN -t)
HERDREX_TRACE=1 nohup ./bin/herdrex --herdr-socket /tmp/rexbridge/herdr.sock --listen 127.0.0.1:7392 >> /tmp/rexbridge/bridge.log 2>&1 &
```

Do not stop or restart any Rex or Herdr server, or create or close sessions in them, unless the user asks; the ones under `/tmp/rexbridge` hold the user's work too. Run live tests only when asked. `docs/TESTING.md` describes the setup; run `rex` with `HOME=/tmp/rexbridge/home`, because `rex hosts add` otherwise writes to the real Rex home and syncs to every device.

Several agent sessions often edit this checkout at once. Stage only your own hunks and leave everything else alone.

## Docs

`docs/` is Chinese with ASCII punctuation (`,` `:` `()`). When bridge behavior changes, update `docs/PROTOCOL.md`: the status in the method and event tables, a record in section 7 and an entry in section 9. `docs/ref/` is generated by `tools/apidoc/gen.py`; don't edit it by hand.

`BRIDGE.md` is the one-page diagram of how herdrex connects Rex and Herdr and how they map. A change to the sockets or protocols used, the package layout, the object mapping, or how input, output and events flow must update `BRIDGE.md` in the same change, together with `docs/PROTOCOL.md` sections 1 and 2, which describe the same things.
