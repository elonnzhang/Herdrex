Flags and startup only; behavior belongs in `internal/bridge`. The CLI uses cobra. Keep `--listen` limited to loopback and Tailscale addresses: the bridge has no authentication. `--add-host` shells out to `rex hosts`; it never edits Rex files itself. `rexBin` finds rex on PATH, else in Rex.app's install paths, and checks `rex version` because Homebrew's `rex` is another program. `--start` and `test` start Herdr only through `pkg/herdr/cli.StartServer`, which refuses anything that could touch the user's Herdr. Cleanup removes sockets only after stopping the server this run started; never remove a socket on a failed start, it may be another server's. `--daemon` re-executes the binary with the same flags in a new session and waits on a pipe (`HERDREX_READY_FD`) until the child serves; the child unsets the variable and marks the descriptor close-on-exec, so a Herdr server it starts does not keep the pipe open.
